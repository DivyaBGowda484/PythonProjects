## Projects 🎮

### 1. Hangman 🪓
A classic word-guessing game where the player tries to guess the hidden word by suggesting letters. The player has a limited number of incorrect guesses before the game ends.

**Features:**
- Word selection from a predefined list.
- ASCII art for different hangman stages.
- A win/lose outcome display.

### 2. Madlib 📝
A fun word game where players fill in the blanks in a story with random nouns, verbs, and adjectives, creating hilarious and unpredictable results.

**Features:**
- Predefined Madlib templates.
- User input to fill in the blanks.
- Random and humorous outcomes.

### 3. Mastermind 🧠
A code-breaking game where the player tries to guess the hidden sequence of colors or numbers in a limited number of attempts. Feedback is provided after each guess to help the player get closer to the correct solution.

**Features:**
- Randomly generated secret sequence.
- Feedback on correct and misplaced guesses.
- Configurable difficulty.

### 4. Number Guessing Game 🔢
A simple game where the player tries to guess a randomly generated number within a certain range. The game gives feedback whether the guess is too high or too low.

**Features:**
- Random number generation.
- User input for guesses.
- Feedback on guesses.
- Adjustable difficulty levels.

### 5. Self-Care Randomizer 🌿
A tool that suggests random self-care activities for you when you're looking for some inspiration. Helps promote mental and physical well-being with fun and relaxing activities.

**Features:**
- A list of self-care suggestions.
- Random activity generator.
- Simple and quick way to boost your day!

### 6. Word Guessing Game ✍️
A simple game where the player tries to guess the randomly chosen word letter by letter. The player has a limited number of attempts to guess the word correctly.

**Features:**
- Random word selection.
- User input for guessing letters.
- Limited number of attempts.

## How to Run the Projects 🛠️

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/python-mini-projects.git
   cd python-mini-projects
   
2. Install any required dependencies (if applicable).

3. Run each project using Python:
   python hangman.py
   python madlib.py
   python mastermind.py
   python number_guessing_game.py
   python self_care_randomizer.py
   python word_guessing_game.py
   
Technologies Used 💻

 - Basic Python libraries like random, time, etc.
